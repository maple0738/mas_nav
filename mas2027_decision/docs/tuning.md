# 调参说明

## 参数一览

| 参数 | 默认 | 含义 | 怎么调 |
|---|---|---|---|
| `enabled` | `false` | 是否发布目标 | 观察阶段保持 false |
| `tick_period_s` | `0.1` | 决策周期 | 一般不动 |
| `goal_frame` | `map` | 目标坐标系 | 无图模式改 `odom` |
| `mirror_points` | `false` | 点表镜像 | 红蓝方切换 |
| `heal_start_s` | `60` | 开局多少秒内不回血 | 按战术，开局抢节奏就调大 |
| `end_rush_s` | `300` | 多少秒后进入末段 | 按 7 分钟赛制，可设 300–330 |
| `heal_enter` | `0.30` | 进入回血的血量比例 | 太低会死、太高会浪费节奏 |
| `heal_exit` | `0.60` | 退出回血的比例 | 必须明显高于 enter |
| `end_rush_hp` | `0.50` | 末段冲锋的血量门槛 | 低于它才冲 |
| `low_bullet` | `20` | 弹药不足阈值 | 结合补弹速度 |
| `base_attack_drop` | `300` | 基地一次掉多少血算被攻击 | 太小会误判，太大会漏判 |
| `base_clear_s` | `5` | 守家事件保持时长 | 保证能跑到位 |
| `patrol_period_s` | `20` | 两个巡逻点之间的驻留时间 | 按场地大小 |
| `goal_dedupe_m` | `0.30` | 目标移动多少才重发 | 小于执行器 0.15 m 容差的两倍最稳 |
| `goal_republish_s` | `3.0` | 兜底重发周期 | 对齐 awakening 的 3 s |

## 调参顺序

1. **点表先对**：示教后逐个发点，确认车能到；点不对，后面所有阈值都白调。
2. **去重**：开日志看 `/goal_pose` 频率。正常情况下只在意图变化时出现，
   不应持续 10 Hz 刷屏。若出现周期性重发导致车一顿一顿，先检查 `goal_dedupe_m`。
3. **回血**：用 `debug_hp_ratio` 手动拉低，确认：
   - 开局 60 s 内不触发；
   - 触发后能到回血点；
   - 拉到 0.6 以上才退出，且不会在 0.3 附近抖动。
4. **末段冲锋**：`debug_game_time_s=310` + `debug_hp_ratio=0.4`，确认直接发敌方基地。
5. **守家**：`debug_ally_base_hp` 从 5000 改成 4600，确认 5 s 内保持守家，之后回到巡逻。
6. **巡逻**：观察 40 s 内是否在两个点之间切换，且不产生多余重发。

## 常见问题

| 现象 | 可能原因 |
|---|---|
| 车不停顿但也不走 | `enabled=false`，或 `points_file` 没加载 |
| 目标发出去车不动 | `goal_frame` 与定位模式不匹配（map/odom） |
| 车一顿一顿 | 目标被高频重发，检查去重与巡逻周期 |
| 一直回血不出去 | `heal_exit` 高于实际可回血量（`max_hp` 未知时按 200 近似） |
| 一直守家 | `base_attack_drop` 太小，或 `ally_base_hp` 基准被残血状态带偏 |
