# 几字型坡道：先到正前方，再对齐上坡

目标是让车体先沿坡前空地完成绕行和转向，移动到坡道入口轴线正前方，再开启 `follow_gimbal`，航向稳定后通过坡面。上坡、下坡和返程使用同一条轴线规则。未调整速度上限、制动能力、硬净空、台阶、侧边或碰撞门。

## 入口行为

1. 全局搜索沿物理坡向向坡道两端各延伸 `0.5 m` 的接近区；该区域内的移动方向与坡轴的绝对点积至少为 `0.8`。横移和主要转弯须在该区域外完成；此字段只约束已有可通行格，不会把未知格或障碍格改成自由空间。
2. MINCO 同时使用实时/累计图的完整坡面和接近区，按前向弧长暴露量形成 `run_up=0.5 m`、`transition=0.1 m` 的平滑门。对助跑段和坡面施加轴线对齐、曲率正则及软角度约束；位置、速度、加速度、积分时间与非局部弧长的梯度一起反传，PRE 和 FINELY 两阶段均生效。没有新增全场高度边缘软代价。
3. 进入坡道准备阶段前，控制器检查**实测位置**与坡道入口：横向偏差不超过 `0.15 m`、位于入口前方，且当前位置的路径切线与入口方向点积至少为 `0.8`。即使制动前视距离很长，也不在侧方提前开启对齐。同一坡道连续对齐时允许额外 `0.05 m` 横向滞回，仍要求处于入口前方且切线方向合格；越界、新坡轴或取消目标会解除。准备阶段使用坡轴作为对齐目标；进入坡面后保留原有路径切线跟随和航向就绪门。
4. 最终轨迹仍经过原净空、台阶、侧边和碰撞门，并对坡面及完整的坡前直线区作方向复核，防止平滑重新切成斜入坡面。累计路线和死胡同恢复也使用方向约束；脱困的中间点允许经过已完成/失败区域，最终前沿目标仍执行原排除规则，避免排除掉整条倒退出口。

坡向数据来自固定快照：在线 `MapSnapshot`、累计 `OnlineGlobalMapSnapshot` 和静态 `TerrainGrid::Snapshot` 共享采样口径。普通/未知标签沿用原几何门；已标为坡面但方向无效或冲突时拒绝穿越，不靠放松硬门恢复。

## 参数与回退

当前配置开启完整链路；修改后需重启导航。

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `planner.directional_terrain.enable` | `true` | 全局方向、接近区、MINCO 正则及最终坡向复核 |
| `planner.directional_terrain.approach_distance` | `0.5` | 坡道两端中心直线接近区，m；按半格修正坡面格中心到边界的偏移 |
| `planner.directional_terrain.min_alignment_cosine` | `0.8` | 搜索及坡面轨迹方向门 |
| `planner.directional_terrain.run_up` / `transition` | `0.5` / `0.1` | 助跑门的弧长范围，m |
| `planner.directional_terrain.saturation_length` | `0.05` | 坡面暴露量饱和弧长，m |
| `planner.directional_terrain.alignment_weight` / `curvature_weight` | `100` / `100` | MINCO 正则权重 |
| `region_control.slope.front_entry.enable` | `true` | 到正前方才开启对齐 |
| `region_control.slope.front_entry.lateral_tolerance` | `0.15` | 入口轴线横向容差，m |
| `region_control.slope.front_entry.lateral_hysteresis` | `0.05` | 仅同一坡轴连续对齐的额外横向滞回，m |
| `region_control.slope.prepare_distance` | `0.3` | 到正前方后临近坡脚才退出自转，m |
| `gimbal_follow.heading_error_gain_s` | `2.0` | 航向闭环修正增益；120°/s 上限、5°/8°门与0.3 s稳定时间保持 |
| `region_control.slope.front_entry.min_alignment_cosine` | `0.8` | 开启对齐前的路径方向条件 |

回到原行为：把两项 `enable` 设为 `false` 后重启。保留方向规划、只对照提前对齐的影响时，仅关闭 `front_entry.enable`。死胡同中间点的排除修正仍保留，因为它不放松任何安全门。

本会话环境创建 UDP socket 返回 `Operation not permitted`，不能启动 DDS/Gazebo。用户追加授权后已尝试沙箱外启动，执行器自动审批按 `sandbox_approval=false` 拒绝该命令。已实际执行 A/B 入口的 B 预检并记录阻塞；没有新的红蓝闭环数据。因此以下标准仍待验收：实测坡前侧向距离 ≥0.5 m、中央高地无 >10 s 停顿、保留累计图的往返耗时不明显慢于 122.48 s，以及实车通过效果。合成规划器通过不代表底盘动力学或定位误差已经验证。
