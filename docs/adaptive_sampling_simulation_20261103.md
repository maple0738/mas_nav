# 自适应采样仿真点云验证（2026-11-03）

**历史实验记录：后续已删除自适应 enabled 开关，当前空间和时间自适应均为固定功能。下文回退模式仅描述当时实验。**

Small Point-LIO 已加入空间自适应采样，主导航配置启用。体素初始为 0.5 m，范围
0.25–1.0 m；代表点距离中位数经 0.5 s 平滑，以距离 / 15 m 的平方插值
16000–40000 点/s 的目标，再按输入采样时间跨度换算目标点数。每批仅执行一次
体素采样，带 10% 死区的有界比例反馈调整下一批分辨率。空输入或不在 1–200 ms
范围内的时间跨度不训练控制器；重置清除历史。该设计借鉴自适应采样思路，未复制
z-localization 的完整 PD 控制、双层代表点采样或时间窗口调度。

## 测试方法与边界

- 启动现有 Gazebo Harmonic RMUC 2025 双 MID360 场景，独立 ROS 域 183，
  `gui:=false rviz:=false use_navigation:=false`。采集右侧真实渲染点云
  `/sim/points/right` 的 120 帧；收到帧首尾跨度 7.8 s。测试包含基地附近静止、
  云台/底盘转动及短距离移动，底盘首末位置约 (3.400,9.500) → (3.533,9.384)。
- 仿真原本通过真值直接发布 `/Odometry`，没有启动 Small Point-LIO，也没有提供
  真实 IMU。因此本次是仿真点云驱动的采样/预处理验证，不是 LIO 或导航闭环验收。
- Gazebo 输出的是无逐点时间的瞬时快照。离线测试按照雷达配置的 20 Hz 周期，
  为每帧赋予约 50 ms 的均匀逐点时间，直接调用新构建库中的 `Preprocess`。
  这些时间只用于运行采样控制和时间排序，不用于生成定位精度结论。丢帧不会被
  当作更长的采样窗口；没有用真值伪造 IMU 或估计结果。
- 采集后停止仿真，载入同一份点云，在同一进程中交替 A/B 顺序运行；先预热一对，
  再固定采样、自适应采样各运行 5 遍。用线程 CPU 时钟测量每帧完整预处理，包含
  过滤、采样、统计及点排序/入队，不包含文件读取、输入时间赋值、滤波、匹配和发布。
  完整数据每次运行约 558 万有效点。

## 结果

| 指标 | 固定 0.5 m | 自适应 |
|---|---:|---:|
| 平均定位点数 / 帧 | 1913.11 | 1368.75 |
| 后 90 帧平均定位点数 | 1860.77 | 1373.88 |
| 平均完整点数 / 帧 | 46466.03 | 46466.03 |
| 120 帧预处理 CPU 时间中位数 | 222.97 ms | 217.03 ms |
| 5 遍预处理 CPU 时间范围 | 210.23–253.93 ms | 213.11–229.40 ms |
| 实际使用体素范围 | 0.5 m | 0.5–0.725 m |

定位点数量减少 28.45%，所有帧两种模式的完整点数一致。预处理 CPU 时间中位数
降低 2.66%，但两组范围重叠，不能据此认定有稳定 CPU 收益；更不能将该数值当作
整个 LIO 或整机 CPU 降幅。减少定位点是否在下游搜索/平面拟合/滤波阶段节省时间，
以及是否影响匹配覆盖、轨迹精度，需要真实 LiDAR+IMU 同包 A/B 回放验证。
本次没有验收全场、坡道导航、双雷达融合后的采样表现或运动估计精度。

## 构建与回归

- 本地 Release 构建及安装 Small Point-LIO、驱动和 bringup 配置完成。
  bringup 使用维护环境提供的依赖单独 CMake 配置/安装；没有重启实车节点。
- 三组功能测试共 10 项全部通过：7 项自适应采样、2 项批量滤波、1 项完整帧边界。
  覆盖反馈方向、体素边界、场景尺度、采样周期、空/异常时间输入、非法配置、
  密集平面点数下降、完整点云保留、时间顺序、重置、固定采样等价及完全旁路。
- 实际 ROS 参数解析通过；源码与安装后的主导航配置一致；`git diff --check` 通过。
- 测试环境同时存在旧维护安装和新 active 安装，运行测试时显式优先加载新库，
  防止 `LD_LIBRARY_PATH` 导致旧库与新头文件混用。

数据与复现程序保存在本地 `.scratch/adaptive-sampling-20261103/`，不纳入版本库：
`capture.json`、`frames.bin`、`collect.py`、`benchmark.cpp`、`benchmark.csv`、
`summary.json`、`sampling-provenance.json` 及仿真日志。仿真进程已关闭。

将主导航配置的 `adaptive_sampling.enabled` 设为 `false` 可恢复固定 0.5 m；
`space_downsample: false` 则跳过两种采样模式。调参项与行为详见 Small Point-LIO README。
