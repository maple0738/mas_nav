# Small Point-LIO 平面复用与 IMU 输出预测

日期：2026-11-03。保留 Small Point-LIO 与已固化的时间、空间自适应，借鉴 z-localization 的局部几何复用、估计与输出分离思路。没有重新引入 ZLIO 前端。

## 实现与边界

- `plane_cache.h`：1024 槽有界缓存，以有序五个支撑点的全部浮点位作为键。命中复用法向、平面偏置和支撑点最大残差，省去重复协方差/特征值分解；查询点残差和雅可比仍逐点计算。继续使用原来的 SmallIVox 搜索及地图淘汰规则，哈希冲突进行完整键比较，不持有地图指针。地图点改变自然失配，重置时清空。
- 这不是直接移植 VoxelMap/八叉树，也不是对变化支撑点做近似复用。没有增加平面内原始历史点的累积存储。
- `output_prediction.h`：独立状态接收主滤波器后验，重放后验时刻之后的 IMU，再随 IMU 外推位置、速度和姿态；使用中点积分、已有重力/零偏、原始 IMU 单位的饱和检查。预测状态不回写 ESKF，地图和稠密去畸变点云继续使用原估计链路。
- 默认高频 `/Odometry` 由 IMU 预测输出，保留原输出限频；关闭原有 `publish_odometry_without_downsample` 时仍走帧级后验输出。没有新增优化切换参数。
- 后验超过 150 ms 未更新则停止预测输出；IMU 间隔超过 100 ms、非法值、重置会使预测失效，须有效后验重新校正。保留最多 1000 条且不超过 2 s 的 IMU 历史。时间戳不倒退。
- 预测独立的是状态，并未创建独立执行线程；仍受 ROS 回调调度和单次点云计算阻塞影响。未增加预测协方差传播，不声称等价于 ZLIO 的完整输出模块。

## 验证方法

使用 `/home/jsy/Projects/navigation/rosbag2_mapping` 前 60 s，以正常 1× 回放、前 10 s 预热。对照为改动前独立保存的可执行文件和匹配共享库；两者均启用已固化时间、空间自适应。测试统一使用 SI 加速度配置及正确的 3g 饱和阈值，生产原始 g 单位配置不变。

CPU 是 LIO 子进程 user+system / 稳态墙钟时间，以一个逻辑核心的百分比表示，不包括回放发布器。消息年龄以回放起点和消息时间戳计算，包含回放调度、传输和处理；不是传感器到控制器的实车端到端延迟。可靠输入并核对完整接收，保存输出轨迹、进程样本和运行日志。

基准脚本新增 `--executable`、`--library-path` 支持旧二进制对照，`--label` 只影响结果名称；增加输出时间戳严格递增健康检查。

## 最终短段结果

最终新旧版本各跑一次，期间没有并发编译或另一组基准。证据分别位于 `.scratch/lio-cache-prediction-20261103/verified-baseline/0-baseline/` 和 `verified-optimized/0-optimized/`；同目录上层的 `binary-sha256.json` 记录二进制校验值。调试期间的其他运行不纳入本表。

| 指标 | 改动前 | 缓存＋独立预测 |
| --- | ---: | ---: |
| 稳态单核 CPU | 5.90% | 6.10% |
| 稳态 CPU 时间 | 2.95 s | 3.05 s |
| 全程 CPU 时间 | 3.49 s | 3.65 s |
| 峰值 RSS | 38.77 MiB | 39.22 MiB |
| 里程计消息年龄 P95 | 83.13 ms | 2.75 ms |
| 稳态里程计频率 | 82.36 Hz | 78.94 Hz |
| 末尾里程计落后 | 89.72 ms | 9.43 ms |
| 点更新批次 | 17339 | 17339 |
| 接受匹配 | 522962 | 522950 |

两者均完整接收 899 帧、12001 条 IMU、11737636 个筛选后输入点；输出有限、时间戳严格递增，健康检查通过。匹配量差 12（约 0.0023%），不宣称数值逐位一致。原有点云发布节流及 best-effort 输出仍存在：订阅端分别收到 884/883 帧、4590956/4585375 点，因此不能用发布后点数推断采样输入丢失；两边输入接收审计均完整。

缓存命中 397155 次、未命中 341869 次，命中率 53.74%，命中时避免重复特征分解。组合改动的 CPU 增加约 0.20 个单核百分点（相对 +3.39%），RSS 增加约 0.45 MiB；消息年龄 P95 减少约 96.7%。因此本轮主要证明了输出时效改善，没有证明整体 CPU 下降，也未通过独立消融量化缓存本身的 CPU 收益。每版仅一次短段运行，不作统计显著性结论。

## 回归与限制

Release 重建安装；原 16 项 C++ 功能回归与新增 5 项缓存/预测回归通过，覆盖精确键命中和失配、后验重放、重力/零偏/单位、饱和、过期/间断、乱序输入及非法后验；6 项录包解码和参数回归通过。

短段回放没有位姿真值，不能据此判断精度提升。更接近当前时刻的输出可能改变控制器看到的短时噪声与修正跳变量，尚未测试实车导航闭环、长时间失锁恢复或动态初始化。
