# Small Point-LIO CPU 优化与记录包复测

日期：2026-11-03。基准对照为 `fd164a3` 后的已安装 Small Point-LIO，包含时间、空间自适应、平面缓存和独立 IMU 输出预测。

## 本轮实现

- 固定外参时，观测雅可比后六列恒为零，将批次信息累积和线性求解由 12 维缩至 6 维。完整 30 维状态和协方差仍参与更新，包括与其他状态的交叉协方差；在线估计外参时继续走 12 维路径。没有降低点数、更新频率或状态维数。
- `point_batch`、`compensated` 改为实例缓冲区，跨回调/批次保留容量并清空内容，避免每次 IMU 回调及点批次重新分配。重置时清空内容。
- IMU 预测用 `upper_bound` 定位第一个未积分区间，避免每次从最多两秒历史的开头遍历。后验校正仍按原顺序重放，积分公式、过期/间断保护不变。
- 没有新增切换开关，采样预算、地图参数和里程计发布间隔沿用原值。

## 正式验证方法

用户记录包 `/home/jsy/Projects/navigation/rosbag2_mapping` 的前 60 s，正常 1×，前 10 s 预热，新旧各两次，顺序为旧—新—新—旧。正式回放期间没有并发编译、诊断或另一组基准。旧版使用独立保存的可执行文件和匹配共享库，新版使用本轮 Release 安装。

## 正式结果

| 顺序 | 版本 | 稳态单核 CPU | 峰值 RSS | 消息年龄 P95 |

| 1 | 旧版 | 6.064% | 38.70 MiB | 2.80 ms |
| 2 | 新版 | 6.044% | 38.70 MiB | 2.78 ms |
| 3 | 新版 | 6.004% | 38.65 MiB | 2.92 ms |
| 4 | 旧版 | 6.084% | 38.59 MiB | 2.64 ms |

两次均值：CPU 6.074%→6.024%，减少 0.050 个单核百分点，相对减少约 0.82%；全程 CPU 时间均值 3.625→3.565 s；峰值 RSS 的两次均值 38.645→38.674 MiB。两次消息年龄 P95 的均值为 2.72→2.85 ms（这是各次 P95 的平均，并非合并样本的 P95），稳态里程计频率均约 78.94 Hz。结果说明本轮实际 CPU 收益很小，不足以声称显著提升。

四轮均完整接收 899 帧、12001 条 IMU、11737636 个筛选输入点；批次均 17339、有效匹配均 522950，输出均为 883 帧、4585375 点。输出有限、时间戳严格递增，末尾里程计落后均 9.43 ms，所有健康检查通过。

每对新旧轨迹均有 4656 个完全相同的消息时间戳；直接比较相同时间戳位置（未插值或刚体对齐），两对 RMS 差均为 1.161e-6 m，最大差 3.563e-5 m。它说明此短段数值变化很小，不是精度真值评价。

证据保存在 `.scratch/lio-cpu-optimization-20261103/`：四轮 `run-*/0-*/result.json`、轨迹、采样、参数和日志，`summary.json` 保存汇总与共享库 SHA-256；`profile/` 保存临时诊断的结果和计时生成脚本。热点诊断结果与正式 CPU 结果分开保存。临时目录的原始副本位于 `/tmp/lio-cpu-profile-20261103/`。

## 回归与限制

Release 重建安装，24 项 C++ 功能回归、6 项录包解码/参数回归、Python 编译和 diff 检查通过。新增测试覆盖五组带完整交叉协方差的 6/12 维结果一致性（状态、协方差及位姿信息误差容限 1e-11）、在线外参仍被更新，以及 1000 条 IMU 期间历史淘汰和样本间后验校正的解析运动检查。

短段录包没有位姿真值；数学上的等价求解存在浮点舍入差异，不承诺长时轨迹逐位一致。本轮未测试实车闭环、整套导航 CPU 或长时运行峰值内存。
